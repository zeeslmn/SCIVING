# SCIVING - Platform Undangan Pernikahan Digital

Aplikasi web modern pembuat undangan pernikahan digital (*digital wedding invitation SaaS*) oleh **Solusi Cerdas Infratech (SCIVING)**, terinspirasi dari fitur terbaik platform seperti **felaria.app**.

## ✨ Fitur Unggulan

### 1. Template Undangan Eksklusif (`/invite/[slug]`)
- **Cover Interaktif & Wax Seal**: Layar pembuka dengan sapaan nama tamu personal (`?to=Nama+Tamu`) dan tombol *"Buka Undangan"*.
- **Pemutar Musik Romantis**: Audio otomatis memutar saat cover dibuka dengan piringan vinyl animasi & tombol kendali mengambang (*floating*).
- **Hero & Countdown**: Tipografi mewah (*champagne & gold accent*), foto mempelai, dan hitung mundur hari/jam/menit/detik secara *real-time*.
- **Profil Mempelai**: Foto, nama lengkap bergelar, nama orang tua, dan tautan Instagram kedua mempelai.
- **Rangkaian Acara**: Kartu Akad Nikah & Resepsi dengan integrasi Google Maps dan tombol *"Simpan ke Kalender"*.
- **Linimasa Kisah Cinta (Love Story)**: Rangkaian cerita perjalanan cinta dari pertemuan pertama hingga hari bahagia.
- **Galeri Foto & Lightbox**: Grid foto kebersamaan dengan fitur klik untuk memperbesar (*modal viewer*).
- **Amplop Digital & QRIS**: Rekening bank (BCA, Mandiri, dll) dengan fitur 1-klik salin nomor rekening, barcode QRIS, dan alamat pengiriman kado fisik.
- **RSVP & Konfirmasi Kehadiran**: Form status kehadiran (Hadir / Ragu / Tidak Hadir), jumlah tamu, dan pesan doa restu dengan animasi *confetti* perayaan.
- **Buku Tamu / Doa (Wishes)**: Kolom aliran pesan dan doa tulus dari para tamu secara langsung.
- **Navigasi Mengambang (Bottom Dock)**: Menu pintasan mobile-first untuk memudahkan tamu melompat antar-seksi.

### 2. Studio Pengantin / Dashboard (`/dashboard`)
- **Manajemen Daftar Tamu**: Tambah daftar tamu undangan lengkap dengan nama dan kategori (VIP, Keluarga, Teman, Rekan Kerja).
- **Generator Link Personal**: Otomatis menghasilkan tautan unik untuk setiap tamu.
- **Kirim WhatsApp 1-Klik**: Menyiapkan draf kalimat undangan yang sopan dan rapi di WhatsApp lengkap dengan link personal tamu.
- **Statistik & Rekapitulasi**: Pantau total tamu, jumlah yang telah mengonfirmasi hadir, dan pesan yang masuk.

### 3. Halaman Depan & Showcase (`/`)
- Katalog desain tema (Sealed Luxury, Editorial Vogue, Sekar Floral).
- Informasi fitur dan nilai lebih.
- Rincian harga transparan (Model sekali bayar).

## 🚀 Cara Menjalankan di Komputer Lokal

1. Buka terminal di folder proyek ini (`d:\Website Invitation`).
2. Jalankan server pengembangan Next.js:
   ```bash
   npm run dev
   ```
3. Buka browser di [http://localhost:3000](http://localhost:3000):
   - **Halaman Depan**: `http://localhost:3000`
   - **Dashboard Pengantin**: `http://localhost:3000/dashboard`
   - **Contoh Undangan Tamu**: `http://localhost:3000/invite/raditya-dan-sekar?to=Bpk.+Bambang+Sutrisno+dan+Keluarga`
